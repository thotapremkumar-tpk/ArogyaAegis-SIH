Changes from the v1 board

  • The power bank is replaced by a Li-Po, BQ24074 charger and TPS63802 feeding the 3V3 pin
  • AD8232 SDN moves from 3V3 to GPIO10, so the ECG is off while charging
  • The DRV8833's second channel (GPIO13) drives a back motor
  • The OLED shares the new I²C bus (0x3C, no address clash)

Build notes

  • All GND pins join one ground; the AD8232 and GSR join it at a single point near the regulator
  • Combined I²C pull-up should be 2.2 kΩ or higher: remove extra resistors on breakout boards
  • GPIO38 drives the DevKit's RGB LED (board v1.1); it will flicker during SD writes, which does no harm
  • Free pins GPIO2 and GPIO42 can drive a second DRV8833 for 4 haptic zones

Pins to avoid

  • GPIO3, 45, 46: strapping pins
  • GPIO26–37: flash and octal PSRAM on N8R8
  • ADC2 pins (GPIO11–20) cannot be read while the radio is on, so both analog inputs use ADC1
